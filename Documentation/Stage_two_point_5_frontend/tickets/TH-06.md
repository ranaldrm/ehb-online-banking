# EHB Ticket TH-06 — Show the Transaction History

## Objective

On the account details page, list that account's transactions. If there are
none, show a friendly "No transactions" message instead of an empty table.

---

## Background for beginners

### The data and its exact field names

`AccountService` already has:

```java
List<Transaction> getTransactionHistory(String accountNumber)
```

Map each `Transaction` to the `TransactionResponse` record (there is a
`TransactionResponse.from(transaction)` factory), just like
`AccountController.getTransactionHistory` does.

> **Watch the field names — they are not what you might guess.**
> `TransactionResponse` exposes:
>
> - `identifier` (the transaction id)
> - `transactionType` (an enum: `INCOMING` or `OUTGOING`)
> - `transactionAmount` ← **not** `amount`
> - `timestamp`
>
> If you write `${t.amount}` the page will fail, because the field is
> `transactionAmount`.

### `th:if` and `th:unless` — show something only sometimes

```html
<p th:if="${list.isEmpty()}">Nothing here</p>
<table th:unless="${list.isEmpty()}"> ... </table>
```

- `th:if="${condition}"` → the element is rendered only when the condition is true.
- `th:unless="${condition}"` → rendered only when the condition is false.

That is all the conditional syntax you need. Do not go learning the rest of
Thymeleaf's conditionals right now.

---

## Worked example (an *orders* history, so you build the transactions one)

**Controller (adding to an existing details method):**

```java
List<OrderResponse> orders = orderService.getOrdersFor(id)
        .stream()
        .map(OrderResponse::from)
        .toList();
model.addAttribute("orders", orders);
```

**Template:**

```html
<h2>Order history</h2>

<p th:if="${orders.isEmpty()}">No orders</p>

<table th:unless="${orders.isEmpty()}">
    <tr>
        <th>Type</th>
        <th>Amount</th>
        <th>When</th>
    </tr>
    <tr th:each="order : ${orders}">
        <td th:text="${order.type}">type</td>
        <td th:text="${order.total}">total</td>
        <td th:text="${order.placedAt}">when</td>
    </tr>
</table>
```

## Your task

1. In your `GET /accounts/{accountNumber}` method (from TH-05), also call
   `accountService.getTransactionHistory(accountNumber)`, map each `Transaction`
   to a `TransactionResponse`, and add the list to the model.
2. In `account-details.html`, below the account details:
   - if the list is empty, show a short message such as `No transactions`;
   - otherwise, loop with `th:each` and show for each transaction its
     `transactionType`, `transactionAmount`, and `timestamp`.

## Verify

- Account `1111` and `4444` each have one `INCOMING` transaction (the seeded
  £500 deposit), so their history should show one row.
- Accounts `2222`, `3333`, `5555` start with **no** transactions, so they should
  show your "No transactions" message.
- Later, after you build the deposit/withdraw forms, revisit these pages and
  confirm new rows appear.

## Concepts practised

- a second `th:each` on the same page;
- `th:if` / `th:unless` for empty-state handling;
- using the correct record field names (`transactionAmount`, `transactionType`).

## Done when

- accounts with history show their transactions;
- accounts with none show a clear message instead of a blank table.
